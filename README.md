## 📖 Sobre o Projeto

Este repositório reúne **diversas atividades e exercícios desenvolvidos em Python** com o objetivo de praticar e compreender o funcionamento dos **operadores aritméticos**. 🧮🐍

Durante as atividades, são exploradas diferentes operações matemáticas fundamentais para o desenvolvimento da lógica de programação.

---

## ➕➖✖️➗ Operadores Trabalhados

Neste repositório, você encontrará exercícios envolvendo:

| Operador | Nome             | Exemplo  |
| :------: | ---------------- | -------- |
|   ➕ `+`  | Adição           | `5 + 2`  |
|   ➖ `-`  | Subtração        | `5 - 2`  |
|  ✖️ `*`  | Multiplicação    | `5 * 2`  |
|   ➗ `/`  | Divisão          | `5 / 2`  |
|  🔢 `//` | Divisão Inteira  | `5 // 2` |
|  🎯 `%`  | Resto da Divisão | `5 % 2`  |
|  🚀 `**` | Potenciação      | `5 ** 2` |
